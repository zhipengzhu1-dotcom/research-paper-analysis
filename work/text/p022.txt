able to carry out designs efficiently, without excessively relying on tools during a design campaign, which becomes
important for expensive tool calls. We note that we ramp up the tool call penalty linearly from 0 to the target value
over 1000 group scoring steps, where the number of group scoring steps in a trainer step is the ratio of the batch
size to the group size, e.g., for a batch size of 1024 and a group size of 16, each trainer step corresponds to 64 group
scoring steps. When doing curriculum training with a mixture of Tier-1 and Tier-2 tasks as in the T1(a)–Mix(b)
models, we scale the number of tool call penalty warmup steps to 250 for the Tier-1 tasks and 750 for the Tier-2
tasks so that the full tool call penalty takes effect for both sets of tasks at the same trainer step. We found that this
linear warmup is important for the model to learn how to use the tools. Without the warmup, the model would
learn catastrophically conservative tool call behavior.
